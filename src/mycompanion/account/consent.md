## 画面2 感情の推定と記憶

> **あなたの気持ちと、会話の記憶について**
>
> FureAI ペルソナ は、次のことを行います。
>
> **感情の推定**
> 会話の内容から、AI があなたの気持ち(例: 「不安が強そう」「うれしそう」)を推しはかり、キャラクタの返事の内容や口調を調整します。推定は AI の見立てであり、診断ではありません。危険を感じるような内容(自分を傷つけたい気持ちなど)を見つけた場合は、相談窓口をご案内します。
>
> **記憶**
> 会話の内容を、AI が要約して「記憶」として保存し、後の会話で思い出します。
>
> - その日の記憶は、翌朝にまとめられ、【90】日ほど保存されます。大切なことや繰り返し話したことは、長く保存されます。
> - 会話の原文は【30】日で削除されます。
> - 記憶と感情の履歴は、いつでも確認・訂正・削除できます。キャラクタが話題に出さないようにもできます。
> - 健康や信条など、センシティブな内容は、あとで別に同意をいただいた場合だけ記憶に残します。同意がなければ、その日のうちに削除します。
>
> 感情の推定や記憶を、広告や他社への販売、引き留め、課金の誘導に使うことはありません。
>
> - [ ] 会話から感情を推定し、返事の調整と安全のための対応に使うことに同意します。
> - [ ] 会話の内容を記憶として保存し、後の会話で使うことに同意します。(あとで設定から取り消せます)
>
> [戻る] [次へ]

## 画面3 AI サービスへの送信と、処理の場所

> **会話を処理する場所について**
>
> キャラクタの返事を作るため、あなたの会話の内容、記憶、感情の推定を、**Microsoft の AI サービス(Azure OpenAI)**に送信します。
>
> - **保存は日本国内**で行います。
> - **AI による処理は、日本を含むアジア太平洋地域内**で行われ、**日本国外の国**(【候補国】など)で処理されることがあります。処理される国を事前に特定することはできません。
> - Microsoft は、当社との契約に基づき、当社の指示の範囲でのみデータを処理し、**あなたの会話を AI モデルの学習に使いません**。
> - Microsoft は、AI サービスの不正な利用を防ぐため、入力と返事を自動で検査します。有害な内容の疑いがある場合、Microsoft の担当者が内容を確認することがあります。【修正版の不正利用の監視が承認された場合は、この行を削除】
> - 処理される国の個人情報保護制度と、Microsoft が講じている措置は、[プライバシーポリシー第8条](【URL】#第8条)で説明しています。
>
> - [ ] 会話の内容などを、Microsoft の AI サービスに送信することを許可します。
> - [ ] 上記のとおり、日本国外を含むアジア太平洋地域内で処理されることを確認し、同意します。
>
> この2つに同意いただけない場合は、FureAI ペルソナ をご利用いただけません。
>
> [戻る] [次へ]

>

## 画面5 任意の設定(18歳以上の方のみ)

> **お好みで選べる設定**
>
> どちらも任意です。あとから設定で変更できます。
>
> **センシティブな内容の記憶**
> 健康(病気、通院、服薬など)、信条(宗教、思想など)といったセンシティブな内容を、記憶として長く保存し、後の会話で思い出すことを許可します。
> - 許可しない場合: センシティブな内容は、その日のうちに記憶から削除されます(会話の原文は【30】日で削除されます)。
> - 許可した場合でも、キャラクタがセンシティブな記憶を自分から話題に出すことはありません。
> - 家族や友人など、ほかの人のセンシティブな内容は、許可の有無にかかわらず記憶に残しません。
>
> - [ ] センシティブな内容を記憶に残すことに同意します。
>
> **恋愛的な表現**
> キャラクタの設定によっては、関係が深まると、キャラクタが恋愛的な気持ちを表すことがあります。有効にしない場合、キャラクタとの関係は友情の範囲にとどまります。
>
> - [ ] キャラクタの恋愛的な表現を有効にします。
>

## 同意の記録(実装メモ)

| 記録する項目 | 内容 |
|---|---|
| `type` | 上の表の値 |
| `version` | 本書の版(例: `1.0`)。利用規約・プライバシーポリシーは、それぞれの版 |
| `granted_at` / `revoked_at` | 同意・撤回の日時(UTC) |
| 文面のハッシュ | 表示した文面(画面の全文)の SHA-256(提案 P5) |
| チャンネル | `cli` / `web` / `ios` / `android` / `line` |

- 利用規約・プライバシーポリシー・本書の版が上がり、改めて同意が必要な場合は、次回のログイン時に、変更点の要約とともに、該当する画面だけを再表示する。
- 撤回は、【設定 > 同意の管理】から行う。撤回後の扱いは、プライバシーポリシー第12条のとおり。
- 18歳未満フラグが true から false に変わった場合は、画面5を表示する。false から true に変わった場合は、`sensitive_memory` と `romantic_expression` を撤回扱いにし、保存済みのセンシティブな記憶を削除する(プライバシーポリシー第5条第3項。18歳未満の利用者のセンシティブな情報は、中期・長期の記憶に保存しないため)。削除の前に、その旨を利用者に通知する。
